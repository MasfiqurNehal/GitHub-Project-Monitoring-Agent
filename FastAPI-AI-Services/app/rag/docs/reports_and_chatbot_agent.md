# Reports, Chatbot, and Engineering Agent

## Executive Reports
- **Custom Telemetry Reports**: Generate PDF, CSV, or visual reports summarizing sprint velocity, developer contributions, and repository health.
- **Scheduled Summaries**: Automated weekly or monthly executive summaries highlighting key engineering milestones and potential risks.

## AI Chatbot
- **Floating Chatbot Drawer**: A right-side floating drawer available across GitMonitor pages (except settings/agent view).
- **Multi-Turn Conversation History**: Retains context across questions, allowing users to ask follow-up questions about their projects.
- **SaaS Data Isolation**: Every conversation is securely bound to the authenticated user and organization tenant (`user_id` & `organization_id` scoping).

## AI Engineering Agent
- **Autonomous Engineering Assistant**: An advanced multi-agent system designed for automated repository diagnosis, architectural recommendations, and pull request code reviews.
- **Deep Git Telemetry Analysis**: Synthesizes commit histories, file churn, and developer patterns into actionable recommendations.
