# Pull Requests and Issues Monitoring

## Pull Requests (PRs)
- **PR Lifecycle Tracking**: Monitors open, merged, closed, and draft pull requests across all tenant repositories.
- **Review Speed & Throughput**: Measures PR time-to-first-review, review turnaround duration, and merge latency.
- **Reviewer Insights**: Identifies review bottlenecks and tracks peer review distribution among developers.

## Issues & Bug Tracking
- **Issue Status**: Tracks open, in-progress, and closed GitHub issues.
- **Resolution Velocity**: Calculates average time to resolve issues, labels breakdown, and issue assignee workloads.
- **Project Alignment**: Maps issues directly to associated projects and repositories for holistic milestone oversight.
