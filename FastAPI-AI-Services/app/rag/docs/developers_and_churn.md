# Developers, Code Churn, and Activity Tracking

## Developers
GitMonitor tracks developer contributions and activity metrics while preserving privacy and focus.
- **Developer Profiles**: Maps GitHub usernames and committer emails to team members.
- **Contribution Tracking**: Analyzes commit counts, PR authorship, code review participation, and active working hours.
- **Impact Metrics**: Highlights top contributors, pull request review throughput, and commit consistency across projects.

## Code Churn & Activity Tracking
- **Code Churn Analysis**: Measures high-frequency code modifications, additions, and deletions across repository files. High churn often signals refactoring hot spots or technical debt.
- **File-Level Telemetry**: Identifies unstable or frequently edited source files to help engineers locate potential risk areas.
- **Daily Activity Aggregations**: Aggregates daily telemetry events for historical trend analysis and sprint velocity estimation.
